# 视觉规范（style-spec）

定义成图长什么样。固定规则，不允许偏离。

## 结构优先

- 本文件只约束摄影风格与版式，不能覆盖形态验收。
- 自然图必须先通过 pose-lock.md 与 nature-lookup.md 的原生自然和非拟人化门槛；真实感、氛围和美感不能补偿人为塑形。
- 在 64px 缩略图中应先被读成真实自然，再隐约感到人物与自然共享的宏观形态、动势或处境；不得要求能描出相同人体骨架。
- 共享关系可以来自形、势或意，是视觉押韵而不是描摹。自然画面单独观看时必须先被认作真实自然状态，而不是动作轮廓复制品或任意漂亮配图。

## 画布与布局

- 布局由动作主轴决定，但两个分区始终严格 **50:50**：
  - 纵向长轴体式（倒立、单腿上伸、竖直拉伸）：**4:3 横版左右二联**，人物固定在左、自然固定在右；每栏恰好是 2:3 竖幅。
  - 横向、拱形、收拢体式：**3:4 竖版上下二联（默认 1080×1440）**，自然在上、体式在下；每栏恰好是 3:2 横幅。
- 两张照片直接相接，不添加人工黑线、白线或留白。
- 不使用：边框、圆角卡片、阴影、渐变、水印、文字、图标。

## 色彩

- 整图 **纯黑白**（灰阶）。任何彩色残留都算不合格。
- 保留摄影环境的黑、深灰、中灰和亮灰；背景不强制纯白。
- 禁止把有环境的原片处理成纯白棚拍或透明抠图。

## 质感：黑白摄影风（真实感）

这是本 skill 的灵魂，两类主体都必须像**真实摄影**，不是插画：

- 自然物：真实照片质感——正确的光影、景深、颗粒、材质。像用单反拍的自然风光/微距/动物摄影。
- 人体：真实照片里的人，保留真实皮肤质感、运动服材质、体态。**不是剪影、不是线稿、不是插画**。
- 允许轻微胶片颗粒 / 黑白摄影的对比度，但不过度。
- 自然图优先纪录摄影与自然史摄影的现场感，不使用“雕塑感、史诗感、概念艺术、电影海报、超现实、完美瞬间、极致细节”等会把自然事件设计化的风格指令。
- 真实摄影不等于全画面清晰。允许符合镜头与天气的空气透视、局部运动模糊、前后景失焦、雾气遮挡、轻微曝光不均和颗粒；禁止均匀锐化、过度去雾、HDR 局部反差与发光轮廓。

## 光影与灰阶

- 保留完整灰阶和暗部材质；高光不得大片死白，阴影不得大片死黑。
- 阴影边缘必须符合真实光源尺度，并保留半影、反射填充和表面纹理。禁止均匀黑色楔形、剪纸式阴影或让阴影边界成为新的主轮廓。
- `expansive-light` 与 `soft-flowing` 优先阴天、薄雾、宽光源或柔和掠射光；`strong-grounded` 也不自动等于硬光和极端反差。
- 在 64px 灰阶缩略图中重新判定主表达方式。若光影使 `contour` 漂移为 `mass`，或使 `skeleton` 的节点消失，成图失败。
- 摄影真实性需在正常尺寸下先检查一次：运动介质的快门表现必须一致，远近锐度与景深必须合理，雾气和飞沫不能与主体同时保持不可能的均匀微细节。64px 检查只负责整体读取，不能掩盖局部生成痕迹。
- 合成脚本只做轻微、可配置的对比调整；不得靠统一拉高对比制造“摄影感”。

## 体式画面

- 体式是**用户上传的真实原片**，保留房间、地板、墙角、窗光和投影，只在本地做灰度与轻微对比度调整。
- 体式完整可见并保留环境呼吸感。人物可见包围盒默认占面板高度约 70%–82%，目标约 75%；不得超过 90% 或同时贴住上下边缘。只有动作关键端点需要时才接近边缘。
- 横向体式以宽度占比优先：关键端点距左右边缘保留约 4%–7%，并利用 3:2 面板裁掉上下多余环境；不得为了追求高度占比而截断端点。
- 以人物可见包围盒而不是原照片边界计算居中；人物视觉中心应落在所属面板中心左右约 8% 范围内。
- 只通过原片裁切位置调整人物居中；禁止模糊补边、镜像延展、拉伸背景或 AI 扩景。
- 禁止：重新画人体、改体式、换服装、加装饰、加文字。

## 自然画面

- 自然画面是 **AI 生成的真实照片质感黑白图**。
- 主体尺度按对象类型决定。动物、花、贝壳等明确主体通常可占可用画面约 60%–80%；海浪、瀑布、云雾、地貌等环境事件通常占约 35%–65%，为成因、余波和尺度证据保留空间。不得为了显得匹配而把所有自然对象做成居中、孤立、贴边的英雄主体。
- 自然必须处在可信环境中：山有雾和地形、浪有海面、树有土地与天空、花可有暗背景或原生环境。
- 地貌、沙丘、苔藓和岩层等体块型主体必须保留地平线、远近层次、周边地表或其他尺度证据；禁止裁成无法判断大小的孤立团块。苔藓主体与苔藓环境可以自然交叠，但主要体块必须通过原生高度、疏密、纹理尺度、局部灰阶或景深中的至少一种差异被读出；优先保留少量湿岩、树皮、泥土或枯叶作为自然层次，避免主体与周围同时呈现相同密度、相同灰度和全画面等量清晰。
- 一个主意象即可，但环境中的云、雾、水、土地、枝叶属于现场，不视为多余主体。
- 主体不要求与背景完全分离。树枝遮挡、飞雾覆盖、浪组交叠、地貌层叠和局部失焦只要符合拍摄条件，属于真实性证据；融合不能让第一眼焦点消失，主体的主要体块或主关系在 64px 灰阶缩略图中仍应可读。禁止为了轮廓清楚而清空现场杂讯，也禁止用描边、轮廓光、聚光灯或纯黑背景制造人工分离。
- 流动自然必须显示完整或可推断的现场链条：浪要有风、相邻浪组、泡沫或回水证据；瀑布要有入口、岩层导流、湿痕、飞雾或落水冲击证据。只有一条漂亮水体轮廓、其余环境都为它服务的画面不合格。
- 自然画面必须通过 `form / force / meaning` 中至少一条通道与体式呼应；`force / meaning` 通道不要求几何对应（见 pose-lock.md / nature-lookup.md）。
- 若自然图已经真实且结构通过，仅左右朝向或螺旋手性与人物相反，允许在合成前水平翻转自然图。水平翻转只用于统一方向，不得作为扩景、补边或伪造额外环境的手段。
- 禁止规则圆环、完美几何、无来由的精确接触点，以及任何为了匹配动作才出现的非自然弯折。

## 情绪

- 情绪跟随体式：舒展体式要轻盈、打开、有呼吸；力量体式才使用厚重、压迫与高对比；柔软体式强调流动和连续曲线。
- 优先真实的“未完成瞬间”：将起未起、将落未落、仍在承重、正在回转或刚刚安定。时间张力应来自自然行为本身，不通过摆拍、拟人或超现实变形制造。
- 哲学意味应由人物与自然共享的受力和处境自行浮现。不要让每一张都承担宏大象征；系列中允许安静、单纯的结构呼应作为留白。
- 不夸张、不卡通、不滑稽。

## 一句话

> 一张黑白摄影二联图：自然不只在形状上像你，也与你承受同一种力量，处在同一种状态里。
